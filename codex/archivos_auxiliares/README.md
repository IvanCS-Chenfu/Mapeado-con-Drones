# Archivos auxiliares

Esta carpeta guarda artefactos generados o reutilizados por las herramientas de
Codex.

```text
logs/          logs completos, reducidos, sublogs e indices de pruebas
trayectorias/  YAMLs de trayectoria para `run_simulation.sh`
html/          visualizaciones HTML de diagnostico
repeticiones/  datasets `.record` de RawMapDatabase y dumps de grafo `.tsv`
```

Los scripts activos escriben por defecto en estas subcarpetas. Los archivos
historicos que no encajen en estas categorias deben documentarse antes de crear
otra carpeta nueva.
